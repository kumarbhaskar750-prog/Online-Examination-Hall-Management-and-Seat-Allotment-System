# Online-Examination-Hall-Management-and-Seat-Allotment-System

Online Examination Hall Management and Seat Allotment System is a web-based application that manages students, faculty, examination halls, and automatic seat allocation. Coordinators can manage student/faculty records and create examination seating plans, while faculty can log in and view their assigned examination details.

Technologies Used
Node.js & Express.js – Backend and server-side routing
MongoDB & Mongoose – Database management
Handlebars (HBS) – Dynamic web pages
HTML, CSS & JavaScript – Frontend
JWT/Cookies – Authentication and authorization
Validator – Email and phone-number validation
dotenv – Environment configuration
